# Poster

The PDF at `output/pdf/electric-sheep-poster-draft.pdf` is one **24 x 24 inch** page (1728 x 1728 PDF points). It summarizes the collected answers, current classification counts, the dedicated mission × aspiration ratings, the unexpected electric-sheep references in two dream answers, and the published exhibit URL: [https://duke-aipi-han.github.io/XAI-ElectricSheep/](https://duke-aipi-han.github.io/XAI-ElectricSheep/). The plot reads scores from `data/mission-aspiration.json` and model names/access types from `models.json`.

Edit `poster/make_poster.py` to update the poster. Text and charts are generated by the Python script, with no design-tool dependency.

To regenerate (Python 3):

```sh
python3 -m venv tmp/pdf-venv
tmp/pdf-venv/bin/pip install reportlab
tmp/pdf-venv/bin/python poster/make_poster.py
```

Print at actual size / 100%, not fit-to-letter.
